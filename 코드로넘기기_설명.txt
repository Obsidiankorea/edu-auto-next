코드로 넘기기 - 사용 설명
====================================

■ 이게 뭔가요
기존 '나라배움터' 는 화면의 좌표와 색을 보고 마우스로 눌렀습니다.
이 프로그램은 웹페이지 안의 '코드'(class / id / 이름)로 버튼을 직접 누릅니다.

  - 마우스를 움직이지 않습니다.
  - 강의 창이 다른 창 뒤에 있어도 됩니다. (창을 앞으로 끌어내지 않음)
  - 좌표를 잡을 필요가 없습니다. F1/F2 같은 지정이 필요 없습니다.
  - 창 크기를 바꾸거나 다른 모니터로 옮겨도 그대로 동작합니다.


■ 쓰는 순서
1. 강의 화면을 브라우저에 띄웁니다. (그 창에서 '지금 보고 있는 탭' 이어야 합니다)
2. 코드로넘기기.ahk 를 실행합니다.
3. 사이트 목록에서 프로필을 고릅니다. (열려 있는 창에 맞는 것이 자동으로 골라집니다)
4. 상태 칸에 재생/시간/페이지가 제대로 나오는지 확인합니다.
5. [시작 (F9)] 을 누릅니다.

정지는 같은 버튼(■ 정지)이나 F9, 본체 창이 앞에 있을 때는 ESC.

다른 일을 하면서 돌리는 가장 편한 순서
1. [시작 (F9)]
2. [창 밀어두기 (F11)] → 강의 창이 화면 오른쪽 끝으로 비켜납니다
3. 본체 창은 최소화 (오버레이를 누르면 다시 뜹니다)
4. 이제 우상단 오버레이만 가끔 보시면 됩니다. 빨개지면 누르세요.


■ 창 구성
본체 창 : 사이트 / 강의 창 / 차시 목록 / 상태 / [시작] [창 밀어두기] [설정]
          사이트·강의 창·차시 목록 옆의 ↻ 는 목록을 다시 읽는 버튼입니다.
          강의 창   : 영상이 도는 창. 최소화된 창은 목록에 나오지 않습니다 (영상이 멈추므로).
          차시 목록 : 차시 목록이나 학습현황이 있는 창. 보통은 (자동으로 찾기) 그대로 두면 되고,
                      자동으로 못 찾는 사이트에서만 직접 고릅니다. 최소화된 창도 고를 수 있습니다
                      (읽기만 하므로). 고르면 바로 그 창에서 차시 목록을 읽어 상태 칸에 보여 줍니다.
설정 창 : 나머지 세부 설정은 모두 [설정] 안에 있습니다.
          왼쪽  : 자동 동작(퀴즈 자동 포함) · 알림(텔레그램) · 시스템(화면 읽는 주기 포함)
          오른쪽: 작업 중 화면(오버레이) · 단축키 · 사이트 프로필 도구 · 차시
          바꾼 내용은 바로 적용되고, 닫을 때 저장됩니다.


■ 단축키 (설정 → 단축키 에서 바꿀 수 있음)
  시작 / 정지             기본 F9
  창 밀어두기 / 되돌리기  기본 F11
  코드 목록 뽑기          기본 F10
  정지                    ESC  (본체 창이 앞에 있을 때만, 바꿀 수 없음)

  바꾸는 법: 칸을 누르고 원하는 키를 누릅니다. 예) Ctrl+F11, Alt+Shift+P
  비워 두면 그 동작은 단축키 없이 버튼으로만 씁니다. [기본값] 을 누르면 처음대로.
  같은 키를 두 동작에 쓸 수는 없습니다. 쓸 수 없는 키면 알려 주고 예전 키를 유지합니다.
  설정 창이 열려 있는 동안에는 단축키가 잠시 꺼집니다. (칸에 키를 넣을 수 있도록)
  본체 창의 버튼과 바닥글에 지금 쓰는 키가 표시됩니다.


■ 작업 중 오버레이
다른 일을 하는 동안 화면 우상단에 작은 창이 떠서 지금 상태를 보여 줍니다.
[설정] → 작업 중 화면 → 오버레이 에서 크게 / 작게 / 숨김 을 고릅니다.

  크게                               작게
     2/5차시 6/8p                     ▶ 2/5차시 6/8p
   ▶ 12:02/14:44
        📖

  위쪽 줄은 차시와 페이지입니다.  2/5차시 = 전체 5차시 중 2차시,  6/8p = 8페이지 중 6페이지
    페이지가 없는 영상(인트로 등)은 '1/5차시', 차시를 모르면 '6/8p' 만 나옵니다.

  두 가지를 따로 보여 줍니다.
    시간 앞 기호 = 영상         ▶ 초록 재생 중     ❚❚ 주황 멈춤
      재생 상태를 알려 주는 플레이어(산업안전포털)는 그 표시를 믿습니다.
      창이 가려지면 브라우저가 시간 글자를 1분에 한 번쯤만 바꾸는데, 그래도 ▶ 로 둡니다.
    맨 아래 그림 = 자동 넘기기  📖 학습 중(진행)   ☕ 휴식(정지)
                                📝 퀴즈            🎓 강의 완료     ⚠ 확인 필요

  바탕색
    어두운 회색  평소 (진행 중이거나 쉬는 중. 쉬는 중이면 글자가 흐려짐)
    빨강        사람이 봐야 함 (📝 퀴즈 / ⚠ 가려짐 · 못 읽음 · 창 없음)
    초록        강의 완료
  퀴즈를 자동으로 푸는 중이면 빨갛지 않고 '📝 자동' 으로 나옵니다.

  작게 : 진행 중이면 영상 기호(▶/❚❚), 쉬는 중이면 ☕, 그 밖에는 그 상태의 그림.
         확인이 필요할 때는 페이지 자리에 이유가 나옵니다 (📝 퀴즈, ⚠ 가려짐)
  숨김 : 띄우지 않음

  그림은 한 가지 색으로 그려집니다. (윈도우 기본 글자 그리기가 컬러 이모지를 못 그림)

  - 끌면 옮겨집니다. 옮긴 자리는 기억합니다.
  - 그냥 누르면 본체 창이 뜹니다. (최소화해 두었어도)
  - 눌러도 지금 쓰던 엑셀·브라우저의 포커스를 빼앗지 않습니다.
  - 크기를 바꿔도 같은 구석에 붙어 있습니다. (오른쪽 끝 기준으로 자리를 기억)
  - 자리를 처음대로 돌리려면 [설정] → [자리 초기화].


■ 무엇을 자동으로 하나요
  - 영상이 끝나면        → '다음' 을 누릅니다. (마지막 페이지까지 알아서 반복)
  - 재생이 멈춰 있으면   → '재생' 을 누릅니다.
  - 문제풀이가 뜨면      → 기본은 아무것도 누르지 않고 소리·텔레그램으로 알립니다.
                           (직접 푸셔야 합니다. 안 풀면 5분마다 다시 알립니다)
                           '퀴즈는 아무 답이나 누르고 넘어간다' 를 켜면 알아서 넘깁니다 (아래)
  - 마지막 페이지까지 끝 → 소리·텔레그램으로 알리고, 원하면 '닫기' 를 누릅니다.
                           ('다음 차시로' 를 켜면 다음 차시로 넘어갑니다)
  - 사이트 안내창이 뜨면 → '다음 동영상 페이지를 학습하시겠습니까?' 같은 것은 확인을 누릅니다.
                           종료·취소 같은 것이나 처음 보는 것은 누르지 않고 알립니다. (아래)
  - 화면을 못 읽게 되면  → 30초 뒤에 소리·텔레그램으로 알립니다.
  - 진행하는 동안        → 컴퓨터가 잠들지 않게 합니다. (화면은 꺼져도 됩니다)

■ 퀴즈 아무 답이나 누르고 넘어가기  ([설정] → 자동 동작, 기본 꺼짐)
O/X 처럼 아무 답이나 눌러도 넘어가는 퀴즈를 알아서 넘깁니다.
  1) 아무 답이나 하나 누릅니다
  2) 정한 초(기본 3초)만큼 기다린 뒤, '다음 / 확인 / 제출 / next' 같은 버튼이 뜨면 누릅니다
  3) 그래도 퀴즈가 그대로면 한 번 더 해 보고, 두 번 해도 안 넘어가면
     예전처럼 빨갛게 바뀌고 소리·텔레그램으로 알립니다 (정답을 골라야 하는 퀴즈)

  틀리면 다른 답을 누릅니다
    답을 누르고 기다린 뒤, 누른 답에 오답 표시가 붙었으면 아직 안 누른 다른 답을 누릅니다.
    O/X 는 O 가 틀리면 X, 4지선다는 다음 보기 순서로. 모든 답을 눌러 봤으면 그냥 넘깁니다.
    틀린 채로 넘기면 그 페이지가 진도에 들어가지 않는 사이트가 있어서입니다.
    (산업안전포털: O/X 를 틀린 채 넘긴 2차시가 8페이지 중 7페이지만 인정되어 88%)
    오답 표시는 프로필 [문제풀이] 오답표시 에 정규식으로 적습니다. 누른 답의 class·이름에서 찾습니다.
      오답표시 = \bwrong\b|incorrect|오답|틀렸          (비워 두면 이 기본값)

사이트마다 퀴즈 모양이 다르므로 특정 O/X 코드에 기대지 않고 일반 규칙으로 찾습니다.
  누를 답  : 퀴즈 상자 안에 있는 것, 라디오·체크 상자, O·X·①~⑨ 처럼 생긴 버튼
             재생·다음·이전·닫기 같은 조작 버튼과 링크(다른 페이지로 갈 수 있음)는 누르지 않습니다.
             확실한 후보가 없으면 아무것도 누르지 않습니다.
  넘길 것  : 이름이 '다음 / 확인 / 제출 / next ...' 로 시작하는 짧은 버튼, '버튼을 클릭하세요' 풍선
             퀴즈 상자 안의 '확인' 을 조작 줄의 '다음페이지' 보다 먼저 누릅니다.
             ("다음 중 옳은 것은?" 같은 문제 글은 버튼으로 치지 않습니다)
프로필 [문제풀이] 에 보기 / 푼뒤누를것 을 적어 두면 그것을 먼저 씁니다. (비워 둬도 됩니다)

페이지가 막 뜬 직후에는 몇 초 동안 '아직 누를 수 없음' 상태가 있어서, 10초까지는 다시 해 봅니다.


텔레그램은 기존 '나라배움터' 설정에서 봇 토큰과 채팅 ID 를 자동으로 가져옵니다.
[설정] → 알림 → [시험 보내기] 로 확인할 수 있습니다. 봇 토큰은 가려서 보여 줍니다.


■ 화면 읽는 주기  ([설정] → 시스템, 기본 5초)
강의 화면을 몇 초마다 읽을지 정합니다. 1~60초.

  굳이 빠를 필요가 없습니다. 5초나 10초로 두면 훨씬 가볍습니다.
  (무거운 플레이어는 한 번 읽는 데 0.3~0.5초가 걸립니다. 1초마다 읽으면 그만큼 계속 일합니다)

  영상이 잘 돌고 있는 동안에는 이 주기보다도 더 쉽니다.
  남은 시간을 알기 때문에, 끝날 때쯤(최대 1분)까지 자고 있다가 깨어나 다음을 누릅니다.
  퀴즈가 떴을 때·무언가 누르고 기다릴 때·멈춘 것 같을 때는 정해진 주기대로 꼬박꼬박 봅니다.

  오버레이의 시간 표시는 화면을 읽지 않는 동안에도 혼자 흘러갑니다. (멈춘 것처럼 보이지 않게)
  다음에 읽을 때 실제 값으로 다시 맞춥니다.

  영상이 끝난 것은 이렇게 알아챕니다
    - 남은 시간이 0 이 되었을 때
    - 시간이 뒤로 크게 되돌아갔을 때 (존플레이어처럼 끝나면 처음으로 돌아가는 플레이어)
      주기를 길게 두면 04:20 → 00:05 처럼 건너뛰어 읽히므로, '되돌아갔다' 로 판단합니다.


■ 차시가 끝나면 다음 차시로  ([설정] → 차시, 기본 꺼짐)
한 차시가 끝나면 다음 차시를 눌러 이어서 듣습니다.

  차시 목록이 학습창 안에 있으면 (지방자치인재개발원) 그 줄을 바로 누릅니다.
  목록이 따로 있는 창이면 학습창을 닫고 그 창에서 누릅니다. ([차시] 목록창 에 창 제목 일부를 적음)
  본체 창의 '차시 목록' 에서 창을 직접 골랐으면 언제나 그 창을 씁니다. (프로필보다 우선)

  켜고 끄기: 본체 창의 '차시가 끝나면 다음 차시로 (다 들은 차시는 건너뜀)' 체크 (설정 창과 같은 칸)
  상태 칸에  다음차시 : 자동 (켬)   · 다 들은 차시 2·6 건너뜀   처럼 나옵니다.

  고르는 순서
    1) 지금 차시 다음 번호부터, 다 들은 차시(진도율 100)는 건너뛰고 첫 번째
    2) 학습 시간이 00:00:00 인 첫 줄 (아직 안 들은 차시)
    3) 차시 번호를 모르면, 다 듣지 않은 첫 줄
  건너뛴 차시는 상태 칸과 텔레그램에 '(다 들은 6차시는 건너뜀)' 으로 알립니다.
  더 들을 차시가 없으면 소리·텔레그램으로 알리고 멈춥니다.

  다 들었는지는 차시 목록의 진도율로 압니다 (프로필 [차시] 진도율, 또는 표의 '40%' 칸).
  진도율을 읽을 수 없는 줄은 '모름' 으로 보고 건너뛰지 않습니다 (한 번 더 듣는 쪽이 안전).
  학습현황의 학습 시간이 00:00:00 이 아니라고 '들음' 으로 보지는 않습니다.
  (잠깐 재생됐다 넘어간 차시도 00:00:13 처럼 시간이 남기 때문)

  차시를 넘긴 직후에는 새 영상이 실제로 도는 것을 볼 때까지(최대 2분) '끝남' 을 믿지 않습니다.
  새 강의가 늦게 뜨면 지난 영상의 끝난 화면이 잠깐 남아, 한 차시를 더 건너뛸 수 있기 때문입니다.

  페이지 표시가 없는 강의(차시 하나가 영상 한 편)는 영상이 끝나면 그대로 차시 끝으로 봅니다.
  (누를 '다음' 이 있으면 먼저 눌러 보고, 없을 때만 차시 끝으로 봅니다)

  어디까지 들을지
    [설정] → 차시 → '어디까지' 에 숫자를 적으면 그 차시까지만 듣고 멈춥니다. 비우면 끝까지.
    예) 4 → 4차시를 마치면 5차시로 넘어가지 않고 멈추고 알립니다.


■ 전체 차시 보기 ([설정] → 차시 → [목록 읽기])
그 과정이 모두 몇 차시인지, 어디까지 들었는지 읽어서 보여 줍니다. 누르지 않고 읽기만 합니다.

    전체 9차시   ·   들은 것 1   ·   남은 것 8   ·   지금 2차시
     1차시  들음   00:16:59  오리엔테이션
     2차시  안 들음 00:00:00  바이브 코딩 패러다임 + 코딩 에이전트 개관
     ...

  읽는 곳은 이 순서입니다
    1) 본체 창 '차시 목록' 에서 직접 고른 창
    2) 프로필 [차시] 진도창 (학습현황처럼 차시별 학습 시간이 나오는 창)
    3) 프로필 [차시] 목록창 (없으면 학습창 안의 목록)
  학습 시간이 나오는 창에서 읽으면 '들은 것 / 남은 것' 까지 알 수 있고,
  학습창 안의 목록만 있으면 전체 차시 수만 셉니다.

  [시작] 을 누를 때도 (차시 자동이 켜져 있으면) 한 번 읽어 두고, 상태 칸에 '차시 2차시 (전체 9차시)' 로 보여 줍니다.

프로필 [차시] 예
    목록창 = 학습창                              (차시를 누를 창. 또는 목록 창 제목 일부)
    진도창 = 학습현황                            (전체 차시·학습 시간을 읽어 올 창. 없으면 생략)
    차시링크 = id무늬:^list-group-item-(\d+)$ || 무늬:^(\d+)차시$
    학습시간 = 무늬:^\d{1,2}:\d{2}:\d{2}$       (00:00:00 이면 아직 안 들은 것)
    목록열기 = class:toggle                      (목록이 접혀 있는 사이트)
    학습창닫기 = class:btn_out                   (목록 창이 따로일 때만)
    진도율 = class무늬:\bstep\b.*\bp(\d+)\b      (차시 줄 안의 class 에서 진도율 숫자. 100 이면 건너뜀)
    넘기기전 = 닫기                              (같은 창에서 누르기 전에 누를 [누를것]. 예: 영상 창 닫기)

  차시 줄마다 같은 이름의 버튼이 있는 표 (산업안전포털의 '학습하기')
    차시링크 = 버튼:class:takeLesson
    같은 줄의 맨 왼쪽 숫자 = 차시 번호,  '40%' = 진도율,  가장 긴 글 = 차시 이름

  지금 몇 차시인지 ([읽을것] 차시)
    차시 = 무늬:^\d+차시                         화면의 '3차시 : ...' 에서 번호
    차시 = 제목:class:eduVideo                   영상 창 제목이 차시 표의 어느 줄 이름으로 시작하는지
                                                 (제목에 번호가 없는 사이트. 산업안전포털)

  차시링크는 || 로 여러 개 적을 수 있습니다. 앞에서부터 해 보고 줄이 찾히는 것을 씁니다.
  같은 사이트라도 창마다 생김새가 다르기 때문입니다.
  (학습창은 id=list-group-item-2, 학습현황 창은 이름이 '2차시')


■ 사이트마다 다른 점 (프로필로 맞춥니다)
                        산업안전포털                 지방자치인재개발원 (학습창)
  창 제목               ...산업안전포털...           학습창
  '다음' 뒤 재생        자동으로 재생됨              재생을 눌러야 함 (자동 재생이 막힘)
  재생 버튼             상태가 class 에 나옴          누를 때마다 재생·멈춤이 바뀜(전환식)
  재생 여부 판단        버튼 class (pause = 재생 중)  시간이 흐르는지
  페이지 표시           '현재 5페이지/총 8페이지'     '01' 과 '/10' 이 따로
                        또는 '04' '08'
  플레이어 종류         스킨 세 가지 (아래)           플레이어 두 가지 (아래)
  차시 목록             강의실 페이지의 표             학습창 왼쪽 목록
                        (줄마다 '학습하기', 진도율 %)  (class=step p100 이면 다 들음)

한 사이트 안에서 과정마다 플레이어가 다를 수 있습니다.
지방자치인재개발원은 두 가지가 섞여 있어 프로필에 둘 다 || 로 적어 두었습니다.
  ① 페이지형    : 한 차시가 여러 페이지. id=btn-next, class=li-time, currentPageNum
  ② 존플레이어  : 한 차시가 영상 한 편. class=mpv-..., 시간이 '02:36' '04:44' 로 따로,
                  페이지 없음, 조작 줄이 숨어 있어도 코드로는 읽고 누를 수 있음

산업안전포털은 세 가지입니다.
  스킨1 : class=page / curTime / totTime / pageBox
  스킨2 : id=nextBtn / playBtn, 시간·페이지는 class 없는 글자 ('01' '08'), 여러 페이지 + O/X 퀴즈
  스킨3 : 강의실 페이지 안에 바로 뜨는 영상 창 (video.js, class=eduVideo)
          시간은 현재 시간만 있고 전체 시간이 없음 → 영상 class 에 vjs-ended 가 붙으면 끝
          ([상태] 끝남 = class:vjs-ended.  끝남만 보고 판단할 때는 안내창이 뜰 틈으로 8초 기다림)
          끝나면 '다음 동영상 페이지를 학습하시겠습니까?' 안내창 → 확인
  한 과정 안에서도 차시마다 다릅니다 (인트로는 스킨3 한 페이지, 본 차시는 스킨2 여덟 페이지 등).

재생 여부를 알려 주지 않거나 믿을 수 없는 사이트는 [상태] 재생중 을 비워 두면
시간이 흐르는지로 판단합니다. 그리고 [동작] 멈춰있으면 에 재생 버튼을 적어 두면
'시간이 멈춤판단초 동안 안 흐르면 누르고, 그래도 안 흐르면 한 번 더' 누릅니다.
전환식 버튼이라도 두 번 안에 재생 상태로 맞춰집니다.
창이 완전히 가려져 화면이 멈춘 것처럼 보일 때는 누르지 않습니다 (잘 돌던 영상을 세우지 않게).


■ 사이트 안내창 자동 처리  (프로필 [안내창])
사이트가 페이지 안에 띄우는 '안내' 창을 알아서 판단합니다.

  [안내창]
  창 = class:normal && name:안내                                 안내창 자체
  누를글 = 다음 동영상 페이지|이어서 학습|이어보기|학습이 완료되었습니다|학습을 시작
  안누를글 = 종료하시겠습니까|나가시겠습니까|취소하시겠습니까|삭제|재수강|응시
  누를것 = class:submit && name:확인 || name:확인                 안내창 안에서만 찾음

  - 누를글 이 있으면 → 누를것 을 누릅니다.
  - 안누를글 이 있으면 → 절대 누르지 않고, 소리·텔레그램으로 한 번 알립니다.
  - 둘 다 아니면(처음 보는 안내창) → 누르지 않고 내용을 한 번 알립니다. 보고 규칙에 추가하세요.
  - 영상이 재생 중이면 누르지 않습니다.
    확인을 눌러 다음 영상이 떠도 지난 안내창이 화면에 남아 있는 경우가 있어서,
    그걸 또 누르면 차시를 하나씩 더 건너뛰기 때문입니다.
    (시간이 끝까지 갔거나 '끝남' 표시가 있으면 재생 표시가 남아 있어도 끝난 것으로 봅니다)


■ 업데이트 (GitHub)
이 폴더를 GitHub 에서 git clone 으로 받았으면, 켤 때 새 버전이 있는지 조용히 확인합니다.
  - 있으면 바뀐 내용을 보여 주고 '지금 받아서 다시 시작할까요?' 하고 묻습니다.
  - [설정] → [업데이트 확인] 으로 직접 확인할 수도 있습니다. 지금 버전은 본체 창 머리글에 나옵니다.
  - 받을 때는 덮어쓰지 않습니다 (git pull --ff-only).
    이 PC 에서 사이트 프로필 등을 고쳐 두었고 새 버전도 같은 파일을 고쳤으면, 받지 않고 까닭을 보여 줍니다.
  - 켤 때 인터넷이 막혀 있으면 아무 말 없이 넘어갑니다. [업데이트 확인] 을 누르면 까닭을 보여 줍니다.
  - 개인 설정(코드로넘기기.ini: 텔레그램 토큰, 단축키, 오버레이 자리 등)은 GitHub 에 올리지 않으므로
    받아도 그대로 남습니다.
  - exe 로 만든 판이나 zip 으로 받은 폴더는 git 저장소가 아니라서 쓸 수 없습니다.


■ 새 사이트 추가하기 (다른 업체 교육 사이트)
1. 그 사이트의 강의 화면을 띄웁니다.
2. [설정] → 사이트 프로필 → [코드 목록 뽑기] (또는 F10) 을 누르면 코드목록.txt 가 열립니다.
3. 목록에서 다음/재생/시간/페이지에 해당하는 줄을 찾습니다.
   '누를 수 있음: 예' 인 것만 코드로 누를 수 있습니다.
4. [설정] → [폴더 열기] 에서 산업안전포털.ini 를 복사해 이름을 바꾸고, 코드를 고칩니다.
5. 본체 창의 사이트 옆 ↻ 를 누르면 목록에 나타납니다.

프로필에 코드를 적는 법
   class:값          class 이름에 그 글자가 들어간 것
   id:값             id 에 그 글자가 들어간 것
   name:값           화면에 읽히는 이름에 그 글자가 들어간 것
   A && B            둘 다 맞아야 함   예) class:page && name:다음페이지
   A || B            둘 중 되는 것     예) id:nextBtn || class:page
   class:"값"        따옴표로 감싸면 정확히 같은 것만   예) class:"close"
                     (따옴표가 없으면 closeMenu, TabCloseButton 처럼 그 글자가 들어간 것도 맞습니다)
   ※ 어떤 규칙이든 웹페이지 안의 요소만 찾습니다. 브라우저의 탭 닫기·창 닫기 버튼은 잡지 않습니다.

[상태] 재생중 = ...
   재생 버튼의 '이름' 이 상태를 알려주지 않는 사이트가 있습니다.
   (산업안전포털 스킨2 는 재생 중이든 멈췄든 이름이 늘 '재생' 입니다)
   그럴 때 '이 요소가 보이면 재생 중' 이라고 적어 두면 됩니다.
   예) 재생중 = id:playBtn && class:controlBtn pause

[동작] 멈춤판단초 = 6
   재생 시간이 이 초수만큼 그대로일 때에만 '재생' 을 누릅니다.
   상태를 잘못 읽어도 재생 중인 영상을 눌러서 세우는 일이 없게 하는 안전장치입니다.
   (상태가 '멈춤' 이고 + 시간도 멈춰 있을 때만 누릅니다)

[읽을것] 에서만 더 쓸 수 있는 것 (class 도 id 도 없는 글자를 잡을 때)
   무늬:정규식       그 모양에 맞는 글자를 찾음
                     예) 무늬:^\d{1,2}:\d{2}\s*/\s*\d{1,2}:\d{2}$   → "00:08 / 00:08"
   숫자쌍            '01' '08' 처럼 나란히 있는 숫자 두 개 → 현재/전체 페이지

같은 사이트라도 플레이어 스킨이 여러 가지일 수 있습니다.
그럴 때는 || 로 이어 적어 두면 되는 쪽을 알아서 씁니다.
(산업안전포털이 실제로 스킨이 두 가지입니다)

[누를것] 에 새 항목을 추가하면 [설정] → 사이트 프로필 → '눌러보기' 목록에도 바로 나옵니다.
거기서 [누르기] 로 하나씩 눌러 보며 코드가 맞는지 확인하세요.


■ 되는 상황 / 안 되는 상황 (실제로 재본 결과)
  됨   포커스가 다른 창에 있어도                  → 영상 잘 돌아감. 엑셀·웹서핑 해도 됨
  됨   강의 창이 일부만 보여도                    → 조금이라도 보이면 돌아감
  됨   모니터 전원이 꺼져도                       → 창이 살아 있으므로 계속 진행
  안됨 강의 창이 다른 창에 '완전히' 덮였을 때      → 브라우저가 그 화면을 멈춰 버림
  안됨 창을 최소화했을 때                         → 같은 이유로 멈춤
  안됨 그 창에서 다른 탭을 보고 있을 때            → 아예 읽히지 않음
                                                     (상태 칸에 '강의 탭이 앞에 있지 않습니다', 오버레이 '⚠ 탭 바뀜'.
                                                      그동안은 아무것도 누르지 않음. 다른 사이트는 새 창(Ctrl+N)에서 여세요)
  안됨 컴퓨터가 절전에 들어갔을 때                 → '잠들지 않게 한다' 를 켜 두세요

가장 중요한 한 줄
  "강의 창이 화면에 조금이라도 보이게 두세요. 포커스는 아무 창에 있어도 됩니다."

  손이 편한 방법: [창 밀어두기 (F11)]
  화면 오른쪽 끝에 몇 픽셀만 남기고 밀어 두고, 그 몇 픽셀이 가려지지 않도록
  '항상 위' 로 만들어 둡니다. 화면은 거의 안 차지하는데 강의는 계속 갑니다.
  다시 누르면 원래 자리로 돌아옵니다. 프로그램을 끌 때도 자동으로 되돌려 놓습니다.
  남길 폭은 [설정] → 작업 중 화면 → 밀어둘 때 남길 폭 (기본 6 픽셀).

  모니터가 둘 이상일 때
    밀어두기는 '모든 모니터를 합친 화면' 의 바깥 끝으로 밀어냅니다.
    (한 모니터의 오른쪽 끝으로 밀면 옆 모니터로 옮겨질 뿐 숨겨지지 않습니다)
    [설정] → 작업 중 화면 → '쪽' 에서 고릅니다.
      자동   : 창이 있는 쪽에 가까운 바깥으로
               예) 왼쪽 모니터의 강의 창 → 왼쪽 바깥으로 숨고, 오른쪽 작업 모니터는 그대로
      오른쪽 : 항상 전체 화면의 오른쪽 바깥으로
      왼쪽   : 항상 전체 화면의 왼쪽 바깥으로

  포커스를 다른 창에 두고 12초 동안 재본 결과 영상은 02:17 → 02:27 로 정상 진행했습니다.
  반대로 다른 창이 강의 창을 완전히 덮었을 때는 30초 넘게 한 프레임도 움직이지 않았습니다.

  가장 편한 방법은 모니터가 둘이면 강의 창을 다른 모니터에 두는 것,
  하나면 강의 창을 한쪽에 두고 작업 창을 겹치지 않게 놓는 것입니다.

상태 칸에 이것을 직접 보여 줍니다.
  재생 : 재생 중 (시간 흐르는 중)        ← 잘 돌아가는 중
  재생 : 재생 중 (시간이 37초째 그대로)  ← 멈춰 있음
  재생 : 재생 중 (시간 표시만 40초째 그대로 · 창이 가려지면 늦게 바뀜)
                                        ← 플레이어는 재생 중. 브라우저가 시간 글자를 늦게 바꾸는 것
  시간 : 01:29 / 53:49   (5초마다 읽음)  ← 화면을 얼마마다 읽는지. 드물게 읽었으면 ', 지난번은 40초 전'
  창   : 다른 창에 완전히 가려짐         ← 이것이 원인일 때

가려져서 멈춘 것이 10초 넘게 이어지면 소리와 텔레그램으로 알려 줍니다.
읽히지 않게 되면 30초 뒤에 따로 알려 줍니다.


■ 다른 작업을 방해하지 않게 하는 옵션
[설정] → 시스템 → '브라우저 창을 절대 앞으로 가져오지 않는다' (기본 켜짐)
  - 켜짐: 창을 앞으로 끌어내지 않는 방법만 씁니다. 타이핑 중에 창이 튀어나오지 않습니다.
  - 꺼짐: 그 방법이 안 통하는 버튼일 때 다른 방법으로 한 번 더 시도하는데,
          그때는 브라우저 창이 맨 앞으로 나옵니다.


■ 안 될 때
· 상태가 전부 '못 읽음'
  → 강의 화면이 그 브라우저 창에서 '지금 보고 있는 탭' 인지 확인하세요.
     다른 탭으로 옮기면 읽히지 않습니다. (창은 뒤에 있어도 됩니다)
  → 창을 최소화하면 읽히지 않습니다. 가려지는 것은 괜찮습니다.

· 엉뚱한 창을 잡을 때
  → 본체 창의 '강의 창' 목록에서 직접 고르면 그 창만 씁니다.
     창을 고르면 그 사이트에 맞는 프로필도 자동으로 바뀝니다. (직접 바꿔도 됩니다)

· 특정 버튼만 못 찾음
  → 그 버튼이 화면에 보일 때만 코드가 생기는 경우가 있습니다.
     (마우스를 올려야 나타나는 조작 줄 등)
  → 그 버튼이 보이는 상태에서 [코드 목록 뽑기] 를 다시 하세요.

· 눌렀는데 아무 일도 안 일어남
  → 그 버튼이 '누를 수 있음: 아니오' 인 경우입니다.
     영상 위에 그림으로만 그려진 버튼은 코드로 누를 수 없습니다.
     그때는 기존 나라배움터(좌표 방식)를 쓰세요.


■ [참고] 브라우저의 '가림 절전' 기능을 아예 끄는 방법
  ※ 레지스트리를 건드리고 관리자 권한이 필요합니다.
     여러 사람이 쓰는 것이 목적이라면 권하지 않습니다. [창 밀어두기] 로 충분합니다.
     아래는 왜 그런 현상이 생기는지, 정 필요하면 어떻게 하는지 기록해 둔 것입니다.

  기능 이름 : Chromium Native Window Occlusion Detection
  하는 일   : 창이 다른 창에 완전히 덮이면 CPU·전력을 아끼려고 그리기를 중단합니다.
              그래서 강의 영상이 멈춥니다.

  같이 알아둘 것 (Chromium 공식 문서)
    - 화면 잠금(Win+L) 상태에서는 모든 창을 '가려진 것' 으로 봅니다.
    - 다른 가상 데스크톱에 있는 창도 '가려진 것' 으로 봅니다.
    - 최소화는 이것과 다른 별개 처리라서, 이 기능을 꺼도 최소화하면 멈춥니다.

  실제로 재보고 '안 되는 것' 으로 확인한 방법들
    - brave://flags 의 해당 항목        → 항목 자체가 없어졌습니다 (Chromium이 제거)
    - --disable-features=CalculateNativeWinOcclusion     → 효과 없음
    - --disable-backgrounding-occluded-windows           → 효과 없음
    - --disable-features=ApplyNativeOcclusionToCompositor → 효과 없음
    - 덮는 창을 아주 살짝 투명하게 만들기                 → 효과 없음

  남은 방법 (레지스트리 정책, 관리자 권한 + 브라우저 재시작 필요)
    크롬  : reg add "HKLM\SOFTWARE\Policies\Google\Chrome" /v WindowOcclusionEnabled /t REG_DWORD /d 0 /f
    엣지  : reg add "HKLM\SOFTWARE\Policies\Microsoft\Edge" /v WindowOcclusionEnabled /t REG_DWORD /d 0 /f
    브레이브 : HKLM\SOFTWARE\Policies\BraveSoftware\Brave 에 같은 값
               (크롬·엣지는 공식 문서에 있는 정책이고, 브레이브는 문서에 없어 확인이 필요합니다)

    적용됐는지는 brave://policy / chrome://policy 에서 볼 수 있습니다.
    끄면 가려진 창도 계속 그리므로 그만큼 CPU와 배터리를 더 씁니다.
