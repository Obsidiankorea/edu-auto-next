# 코드로 넘기기

온라인 의무교육(산업안전포털, 지방자치인재개발원, 한국보건복지인재원 등) 강의를 **다른 일을 하는 동안 알아서 넘겨 주는** AutoHotkey v2 프로그램입니다.

화면 좌표나 색을 보지 않고, 웹페이지 안의 **코드(class / id / 이름)** 를 Windows UI Automation 으로 읽고 눌러서 넘깁니다.

- 마우스를 움직이지 않습니다. 강의 창이 다른 창 뒤에 있어도 됩니다.
- 영상이 끝나면 다음 페이지, 차시가 끝나면 다음 차시로 넘어갑니다. 다 들은 차시는 건너뜁니다.
- "다음 동영상 페이지를 학습하시겠습니까?" 같은 사이트 안내창은 알아서 판단해 `확인` 을 누릅니다.
- 퀴즈·멈춤·완료를 소리와 텔레그램으로 알립니다.
- 화면 구석의 작은 오버레이로 `2/5차시 5/8p ▶ 06:07/19:00` 처럼 진행 상황을 보여 줍니다.
- 켤 때 GitHub 에 새 버전이 있으면 받을지 묻습니다.

## 시작하기

1. [AutoHotkey v2](https://www.autohotkey.com/) 를 설치합니다.
2. 이 저장소를 받습니다. (업데이트 확인을 쓰려면 zip 이 아니라 `git clone` 으로 받아야 합니다)
   ```bash
   git clone https://github.com/Obsidiankorea/edu-auto-next.git
   ```
3. 강의 화면을 브라우저에 띄우고 `코드로넘기기.ahk` 를 실행합니다.
4. 사이트를 고르고, 필요하면 **"차시가 끝나면 다음 차시로"** 에 체크한 뒤 **F9** 로 시작합니다.

자세한 사용법은 [코드로넘기기_설명.txt](코드로넘기기_설명.txt), 바뀐 내역은 [CHANGELOG.md](CHANGELOG.md) 를 보세요.

다른 사이트는 `사이트` 폴더에 프로필(.ini)을 하나 더 만들면 됩니다. 방법은 설명서의 "새 사이트 추가하기" 를 보세요.

## 업데이트

켤 때 새 버전이 있는지 조용히 확인하고, 있으면 바뀐 내용을 보여 주고 받을지 묻습니다. **[설정] → [업데이트 확인]** 으로 직접 확인할 수도 있습니다. 쓰는 방식에 따라 받는 곳이 다릅니다.

| 쓰는 방식 | 받는 곳 | 받는 법 |
|---|---|---|
| `코드로넘기기.exe` (릴리스 zip 을 받아 쓰는 경우) | [GitHub Releases](https://github.com/Obsidiankorea/edu-auto-next/releases) | 새 zip 을 받아 SHA256 을 확인한 뒤 exe 를 스스로 바꾸고 다시 켭니다 |
| `코드로넘기기.ahk` + `git clone` | 저장소 (`main`) | `git pull --ff-only` |
| `.ahk` 를 파일만 복사해 온 경우 | Releases | 받는 곳을 열어 줍니다 (스스로 바꾸지 않음) |

- 개인 설정(`코드로넘기기.ini`: 텔레그램 토큰, 단축키, 창 위치 등)은 어느 쪽이든 건드리지 않습니다.
- 사이트 프로필: exe 판은 새 프로필을 더하고, 손대지 않은 프로필은 새 판으로 바꾸고, **직접 고친 프로필은 그대로 두고** 새 판을 옆에 `.new` 로 둡니다. git 판은 겹치면 받지 않고 까닭을 보여 줍니다.
- 설치나 레지스트리 설정은 없습니다. 실행 중인 exe 는 덮어쓸 수 없어서, 이름을 `.old` 로 바꿔 두고 새 exe 를 넣은 뒤 다음에 켤 때 지웁니다.
- v1.5.0 이하 exe 에는 이 기능이 없으니 v1.6.0 은 한 번 직접 받아야 합니다.

### 새 버전 올리기 (만드는 사람용)

1. `코드로넘기기.ahk` 의 `appVersion` 을 올리고 `CHANGELOG.md` 에 `## v버전` 칸을 적은 뒤 커밋합니다.
2. `.\release.ps1` → `dist` 폴더에 zip, `SHA256SUMS.txt`, 릴리스 설명(`notes.md`)이 만들어집니다. (빌드만, 올리지 않음)
3. `.\release.ps1 -Publish` → 태그를 만들어 push 하고 GitHub 릴리스에 zip 과 `SHA256SUMS.txt` 를 올립니다. [GitHub CLI](https://cli.github.com/) (`gh`) 로그인이 필요합니다.

exe 는 저장소에 커밋하지 않습니다 (`.gitignore`). 릴리스에만 올립니다.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `코드로넘기기.ahk` | 프로그램 본체 |
| `사이트/*.ini` | 사이트별 프로필 (어떤 코드를 읽고 누를지) |
| `코드로넘기기_설명.txt` | 사용 설명서 |
| `CHANGELOG.md` | 버전별 바뀐 내역 |

저장소에 올리지 않는 것 (`.gitignore`): `코드로넘기기.ini` (개인 설정·텔레그램 토큰), `코드목록.txt` (코드 뽑기 결과), `*_기록.txt`, `*.exe`, `*.bak`, `*.zip`

## 버전 올리는 법 (고치는 사람용)

1. `코드로넘기기.ahk` 맨 위의 `appVersion` 을 올립니다.
2. `CHANGELOG.md` 에 바뀐 내용을 적습니다.
3. 커밋하고 태그를 붙여 올립니다.
   ```bash
   git commit -am "v1.3.1: 무엇을 고쳤는지"
   ```
   ```bash
   git tag v1.3.1
   ```
   ```bash
   git push --follow-tags
   ```
다른 PC 에서는 프로그램을 켜면 새 버전을 알려 줍니다.
